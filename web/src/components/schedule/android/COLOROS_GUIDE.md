# OPPO ColorOS 适配与保活全配置指南

本指南针对 OPPO / 一加 (ColorOS 12 / 13 / 14 / 15) 系统进行专属调优，确保**平时完全不常驻后台、上课前 5 分钟 100% 准时唤醒、下课后彻底释放零耗电**。

---

## 核心配置四步法

### 1. 悬浮窗权限（流体云胶囊基础）
* **路径 1**：首次进入 APP 时在权限引导页点击“悬浮窗权限”，在弹出的系统列表中找到 **snhgn 课表**，开启**“在其他应用上层显示”**。
* **路径 2 (手动)**：系统设置 → 应用 → 应用管理 → **snhgn 课表** → 权限 → 悬浮窗 / 在其他应用上层显示 → 选择**“允许”**。

### 2. 精确闹钟权限（准时唤醒引擎）
* **路径**：系统设置 → 应用 → 特殊应用权限 → **闹钟和提醒 (Alarms & Reminders)** → 找到 **snhgn 课表** → 开启**“允许设置闹钟和提醒”**。
* *说明*：Android 14+ 默认关闭该权限，开启后系统 `AlarmManager` 才能在上课前 5 分钟精准唤醒 BroadcastReceiver。

### 3. 自启动与后台活动权限（防止被多任务卡片杀死）
ColorOS 默认在从多任务划掉卡片时会执行 `am force-stop`，进入 Stopped 状态的应用将无法接收系统闹钟。
* **自启动**：系统设置 → 应用 → 自启动管理 → 找到 **snhgn 课表** → 开启**“允许自启动”**与**“允许关联启动”**。
* **后台耗电管理**：系统设置 → 应用 → 应用管理 → **snhgn 课表** → 耗电管理：
  * 开启 **“允许完全后台行为”**（或“允许后台活动”）。
  * 开启 **“允许唤醒前台”**。

### 4. 电池优化设置为“无限制”
* **路径**：系统设置 → 电池 → 更多设置 → 耗电异常优化 → 找到 **snhgn 课表** → 设置为**“不优化”**（或在应用耗电管理中选择**“无限制”**）。
* *说明*：系统 Doze（深度休眠）模式下，未优化的应用在闹钟触发时不受网络与 CPU 节流限制，可在 3 秒内完成服务器课表核验。

## 推荐操作：多任务界面锁定应用（可选加固）

1. 打开一次 APP 进入课表主页。
2. 从屏幕底部上滑悬停进入**多任务（最近应用）列表**。
3. 点击 **snhgn 课表** 卡片右上角的 **“⋮”** 或长按卡片。
4. 选择 **“锁定” (Lock)**，卡片右上角会出现一个小锁图标 🔒。
* *效果*：即使点击“一键清理”，系统也不会将该进程彻底强杀，确保 AlarmManager 调度表始终处于活跃状态。

## 功耗承诺与后台生命周期说明

本 APP 严格遵从 **“零常驻后台、短生命周期任务”** 原则：
* **平时状态**：无后台 Service、无 WebSocket 长连接、无定时轮询、无常驻通知。
* **上课前 5 分钟 (开始 Alarm)**：系统单次唤醒，耗时 ~1 秒拉取校验，随后弹出流体云胶囊并提升为短生命周期前台服务。
* **课程结束时 (结束 Alarm)**：底层系统闹钟准时唤醒广播发送终结指令，悬浮窗自动移除，`FloatingWindowService` 自动执行 `stopSelf()` 彻底退出，进程归于休眠，后台零多余耗电。
